🏭 INDUSTRIAL EQUIPMENT HEALTH MONITORING

Real-Time Equipment Condition Monitoring Using STM32F446RE and Arduino UNO R4 WiFi

Project Overview

This system monitors the health condition of industrial equipment using multiple sensors interfaced with STM32F446RE.

Sensor measurements are transmitted through Arduino UNO R4 WiFi to ThingsBoard Cloud for real-time monitoring, visualization and equipment condition assessment.

Controller: STM32F446RE Nucleo

Communication: USART1 / WiFi

Cloud Platform: ThingsBoard
